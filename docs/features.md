# 機能一覧

優先度は Must/Should/Could/Won't の4段階(MoSCoW分析)

| 機能名 | 概要 | 優先度 |
| --- | --- | --- |
| ユーザー認証 | アカウント登録・ログイン・ログアウト | Must |
| トピック管理 | 学びたいトピックの作成・一覧・閲覧・削除 | Must |
| 説明の採点 | 説明文を送ると AI が5観点（各0〜100）で採点し、総合点・フィードバック・理解の穴を返す | Must |
| 採点結果の表示 | 総合点・各観点のスコア・フィードバック・理解の穴を結果画面に一覧表示する | Must |
| スコア推移グラフ | トピック内の総合点を時系列の折れ線で表示する | Must |
| トピック編集 | トピックのタイトル・説明を修正する | Should |
| 観点別スコアのレーダー表示 | 5観点のスコアをレーダーチャートで視覚的に表示する | Should |
| 観点別の推移 | 観点ごとの伸びを時系列で表示する | Should |
| 弱点の分析 | 常に低い観点や繰り返し指摘される理解の穴を可視化する | Could |
| ギャップ解消の追跡 | 前回指摘された穴を今回つぶせたかを表示する | Could |
| 復習サジェスト | 習熟度が低い／放置中のトピックを提示する | Could |
| 学習の継続支援 | 連続挑戦日数や達成バッジで継続を促す | Won't |
